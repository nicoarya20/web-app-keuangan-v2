# Project Glossary

| Term | Definition |
| :--- | :--- |
| **MoneyFlow** | The name of the application. |
| **Wallet** | A financial account (e.g., Bank, Cash, E-wallet) where funds are stored. |
| **Edge Function** | Serverless functions hosted on Supabase used for backend logic. |
| **Shadcn/UI** | A collection of re-usable components built using Radix UI and Tailwind CSS. |
| **Radix UI** | Unstyled, accessible components used as the base for our UI. |
| **Supabase** | Backend-as-a-service providing DB, Auth, and Functions. |
| **Transaction** | Any movement of money (Income, Expense, Transfer). |
