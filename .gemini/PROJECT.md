# Project: MoneyFlow

## Overview
MoneyFlow is a comprehensive personal finance management application designed to help users track their financial health across multiple dimensions, including income, expenses, savings, and investments.

## Core Goals
1. **Multi-Wallet Support**: Allow users to manage money across different accounts (Bank, Cash, E-wallet).
2. **Transaction Tracking**: Easy logging and categorization of income and expenses.
3. **Goal-Oriented Savings**: Help users set and track progress toward specific savings targets.
4. **Investment Monitoring**: Provide a clear view of investment performance and portfolio distribution.
5. **Insights & Analytics**: Visualize financial data through an intuitive dashboard.

## Tech Stack
- **Frontend**: React 18 (TypeScript) + Vite
- **Styling**: Tailwind CSS 4 + Radix UI (Shadcn UI components)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Charts**: Recharts
- **Backend**: Supabase (PostgreSQL, Auth, Edge Functions)
- **Routing**: React Router 7

## Target Audience
Individuals looking for a modern, responsive, and secure way to manage their personal finances.
